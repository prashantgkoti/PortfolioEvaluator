How unfamiliar file formats are handled

Every upload goes through up to three tiers, cheapest and most reliable first:
  1. Exact parsers — NSDL CAS PDFs and Zerodha Console tradebooks. Verified against real statements. Always local.
  2. Heuristic column matching — for other .xlsx/.csv tradebook or ledger exports (Motilal Oswal, Angel One, etc.). Looks for recognizable columns (Symbol, ISIN, Date, Qty, Price, Buy/Sell) regardless of exact wording. Always local, no API key needed — this is why formats it hasn't seen before often still work.
  3. AI-assisted extraction — last resort for anything the first two tiers can't confidently parse. Opt-in only, and the one path that sends file content outside this machine.
